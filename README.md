# TidyTuesday 2026

Weekly [#TidyTuesday](https://github.com/rfordatascience/tidytuesday) challenges in R and the web.
Each week has its own folder with the data, R scripts and, where I made one, an interactive page.

**Site:** https://enchikova.github.io/tidytuesday2026/

| Week | Date | Topic | Output |
|---|---|---|---|
| [W42](2026-w42/) | 2026-10-20 | Which college majors are safest from AI, and do they pay? | [Interactive page](https://enchikova.github.io/tidytuesday2026/2026-w42/) |

## Folder layout
```
YYYY-wNN/
  README.md   question, finding, method notes
  R/          scripts (run from the week folder)
  data/       cleaned data used by the output
  index.html  interactive page, if any (served by GitHub Pages)
```
To add a week, copy `_template/` to a new `YYYY-wNN/` folder and add a row to the table above.
